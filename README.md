# Health Track

Health Track is a web-based platform that connects users with doctors for online medical consultations. It allows users to request treatment, doctors to manage their profiles, and admins to oversee the platform.

## 🏥 Live Demo  
🔗 [Health Track](https://health-track-pi.vercel.app)

## 📂 Project Repositories  
- **Client Side**: [Health-Track](https://github.com/jahedasultana/Health-Track)  
- **Server Side**: [Health-Track-server](https://github.com/jahedasultana/Health-Track-server)  

## 🚀 Features
- **User Role**  
  - Request a doctor for treatment  
  - View and update profile  

- **Doctor Role**  
  - View patient requests  
  - Manage profile (add experience, qualifications, etc.)  

- **Admin Role**  
  - Manage users and doctors  
  - Approve or remove doctors  

## 🛠️ Technologies Used
- **Frontend**: React.js, Tailwind CSS , firebase, motion
- **Backend**: Node.js, Express.js  
- **Database**: MongoDB  


## 📌 Installation & Setup
1. Clone the repositories  
   ```bash
   git clone https://github.com/jahedasultana/Health-Track.git
   git clone https://github.com/jahedasultana/Health-Track-server.git
   ```
2. Install dependencies  
   ```bash
   cd Health-Track
   npm install
   cd ../Health-Track-server
   npm install
   ```
3. Start the development server  
   - Client: `npm run dev`  
   - Server:  `nodemon index.js`
